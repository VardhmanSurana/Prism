● Free Setup Guide

Hermes Agent, the free path

From a blank terminal to a real conversation with your own AI agent — no API keys, no config-file surgery, no cost. Just the wizard the installer already gives you.

⏱ ~5 minutes 💳 $0 required 🖥 macOS · Windows · Linux

Hermes Agent is a real, open-source AI agent built by Nous Research (MIT licensed) — it runs in your terminal, remembers things across sessions, and can use tools like the terminal, file system, and web search on your behalf.

Most walkthroughs skip straight to hand-editing YAML files and exporting API keys in your shell profile. You don't need any of that to get started. The installer already ships an interactive setup wizard that does the picking for you — this guide just walks you through it, in order.

01
Step 01 — Install

Install Hermes Agent

Pick the option that matches how you work. If you don't want to touch a terminal at all, use the desktop app.

# Run this in your terminal
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# Then reload your shell so the "hermes" command is available
source ~/.bashrc   # or: source ~/.zshrc

This installs everything it needs automatically — Python, Node.js, and the Hermes CLI itself. No sudo required on most systems.

# Run PowerShell as Administrator
iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Native Windows support is still experimental — if anything feels off, installing WSL2 and using the macOS/Linux command above is the more stable path.

Download the Hermes Desktop installer for macOS or Windows from hermes-agent.nousresearch.com and run it like any other app. It installs the same CLI underneath, plus a graphical window — nothing below in this guide changes.

02
Step 02 — Choose an engine

Run the setup wizard

Type one command. It gives you exactly three modes — pick one, nothing else to configure by hand.

hermes setup

Quick Setup — Nous Portal

Recommended

One free login, no API key to find or paste. Covers a model plus web search, image generation, and text-to-speech under one account.

Full Setup

Walk through every provider and tool yourself. Good once you already have a specific API key you want to use.

Blank Slate

Bare-minimum agent — just a model, file access, and the terminal. Everything else stays off until you turn it on.

03
Step 03 — Introduce yourself

Your first prompt

The very first thing Hermes hears sets the tone for every session after. Fill in the gold parts and paste it in.

Hi Hermes! My name is [YOUR NAME]. I'm a [YOUR ROLE, e.g. video editor, developer, student]. Right now I mainly want help with: [YOUR MAIN GOAL — e.g. researching AI news, writing code, organizing my week]. Please remember these details about me across every session. And before you do anything that spends real money, messages someone else, or changes files outside this project, check with me first.
04
Step 04 — Say hello

Start your first chat

Two ways to launch it — either works, the TUI just looks nicer.

hermes            # classic CLI
hermes --tui      # modern visual interface (recommended)

Once it's up, try something easy to verify:

"Check my current directory and tell me what looks like the main project file."

You're good to go once:

  • The welcome banner shows your model and provider
  • Hermes replies without an error
  • It can use a tool when asked (terminal, file read, web search)
  • The conversation keeps going past one message

Step 05 — Get around

Commands worth knowing

Type / inside a chat any time to see the full list.

CommandWhat it does
/helpShow all available commands
/toolsList what Hermes can currently do
/modelSwitch model or provider on the fly
/saveSave the current conversation
hermes --continueResume your most recent session
hermes doctorDiagnose a setup that's misbehaving
