# Prism Plan

> **Simple at first. Powerful forever.**

---

## Vision

Prism is an offline-first photo and video manager built for everyone.

A first-time user should be able to install Prism, select their Photos folder, and immediately start organizing, browsing, searching, and editing their media — without setup, accounts, servers, or cloud dependencies.

- **No accounts.**
- **No cloud.**
- **No mandatory server.**
- **No initial AI configuration.**

As users grow, Prism grows with them through optional local AI, extensible plugins, background automation, and self-hosted server networking.
