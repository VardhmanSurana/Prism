# Product

## Register

product

## Platform

web

## Users

Everyone from non-developers to professional photographers to software engineers. The primary context is managing, editing, and organizing photos and videos locally, with privacy as a core concern. Users range from casual family photo organizers to professional photographers managing large libraries, to developers who want full control over their media assets.

## Product Purpose

Prism is a privacy-first local photo and video library application. It indexes media from watched folders, extracts EXIF metadata, generates high-speed thumbnails, supports instant FTS5 search, groups media by people/places/memories, provides a non-linear video timeline editor, and secures private media inside an encrypted Locked Folder. All data stays 100% local on the user's machine.

## Positioning

The only local-first photo and video library that combines professional-grade editing, AI-powered organization, and end-to-end encryption — without ever sending your media to the cloud.

## Brand Personality

Clean, confident, powerful. The interface should feel like a precision tool — effortless to use, but obviously capable. No visual clutter, no decorative fluff, just purposeful design that disappears into the task.

## Anti-references

No specific anti-references provided. The design should avoid common AI-generated UI patterns: over-rounded cards, gradient text, decorative glassmorphism, and generic SaaS layouts.

## Design Principles

1. **Local-first by design** — Every feature reinforces that data stays on the user's machine. No cloud prompts, no sync badges, no upload CTAs unless explicitly imported.
2. **Power through restraint** — The interface should feel minimal until the user needs depth, then reveal professional-grade tools without overwhelming the casual user.
3. **Consistent vocabulary** — Same button styles, same form controls, same icon language across every surface. Familiarity breeds trust.
4. **Privacy as presence** — Security features (Locked Folder, encryption) should feel integrated, not bolted on. The user should always know their data is protected.
5. **Performance as UX** — Fast thumbnails, instant search, smooth transitions. The tool should never make the user wait.

## Accessibility & Inclusion

- Keyboard navigation throughout (documented shortcuts in the lightbox and editor)
- Reduced motion support via `prefers-reduced-motion`
- Semantic HTML structure with proper ARIA labels
- Dark theme as default (accessible contrast ratios on dark backgrounds)
- Screen reader support for core navigation and actions
